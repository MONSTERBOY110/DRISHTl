Phone Camera (IP Webcam)

1. Connect phone and laptop to the same Wi-Fi.

2. Install IP Webcam on the phone and tap "Start server".

3. The app shows a base URL like http://10.71.69.10:8080

4. Add /video and paste it here:http://10.71.69.10:8080/video

In IP Webcam, set video resolution to 640×480 or 720p — avoid 1080p/4K on a CPU demo (smoother preview, lower load).

Use http, not https. RTSP apps also work: rtsp://PHONE_IP:8554/live
